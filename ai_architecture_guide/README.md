# AI Systems Architecture Guide

An interactive Streamlit guide to ingestion and vector search, guardrails, and
LLM gateways. It includes a chunking playground, architecture diagrams, option
comparisons, and links to official provider documentation.

Run from the repository root:

```bash
uv run streamlit run ai_architecture_guide/streamlit_app.py
```

Or, with the project virtual environment activated:

```bash
streamlit run ai_architecture_guide/streamlit_app.py
```

The playgrounds are educational simulations. They do not call production
embedding, database, guardrail, or model services.
